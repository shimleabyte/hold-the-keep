## Evidence and confidence rules

- All remote branches were enumerated across both pages of the branches endpoint. All PR records were enumerated across both pages of the all-state pull request endpoint.
- Branch names are not treated as proof of completion. Classification uses the remote branch HEAD SHA, PR head SHA/state/merge commit, known ancestry comparisons, and targeted file-level comparisons.
- `MERGED` means its exact head was merged, or an explicit ancestry comparison established that the tip is already an ancestor of current main.
- `DUPLICATE / SUPERSEDED` means a later integrated branch/PR is its recorded successor. Before deletion, preserve any unique residual diff.
- `INCOMPLETE` means unique work has not been proven integrated. It is retained pending source-level comparison and CI review.
- `ACTIVE` means the branch contains a relevant candidate workstream requiring follow-up validation; it is not a claim that it is ready to merge.
- `BLOCKED / DEFERRED` means it is outside current scope or conflicts with the approved gameplay contract.
- The branch API provides name and HEAD SHA. Commit dates and subjects were not uniformly retrieved for every historical PR branch. Each HEAD SHA links to its GitHub commit page. CI status for historical branch tips is not claimed unless explicitly noted; current main and the named superseding integrations are evidenced separately.
